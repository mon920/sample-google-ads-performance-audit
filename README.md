# Google Ads Performance Audit

Interactive performance audit built with Python, Pandas, and Streamlit for a simulated B2B financial acquisition account.

## Business objective

Evaluate Google Ads performance using opened accounts as the primary conversion instead of leads or booked demos, connecting media investment with a deeper business outcome.

## Funnel analyzed

Click → Application → Approved Application → Opened Account

## Key metrics

- CTR
- CPC
- Application Rate
- Approval Rate
- Account Opening Rate
- CPA per opened account
- CPA vs. target

## Features

- Campaign-level performance classification
- CPA comparison against campaign targets
- Funnel-based automated recommendations
- Executive performance summary
- Interactive dashboard and downloadable results

## Performance status

- Cumple: CPA is at or below target
- Monitorear: CPA is up to 20% above target
- Requiere atención: CPA is more than 20% above target

## Technology

- Python
- Pandas
- Streamlit

## Data disclaimer

All campaign data used in this project is simulated and was created exclusively to demonstrate the audit methodology and automation workflow.
